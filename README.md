# Smart-Library-Management-System
Smart Library is a website that helps manage books, students, and library activities easily. Students can search and borrow books, while librarians can manage book records.
# Smart Library Management System

## Project Description
Smart Library Management System is a web-based application developed using Python and Flask. It helps manage books, students, and library activities efficiently.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- SQLite (if configured in the project)

## Modules
1. Admin Login
2. Dashboard
3. Book Management
4. Student Management
5. Book Search
6. Book Issue and Return (if implemented)

## Main Features
- Manage book records.
- Search for available books.
- Manage student information.
- User-friendly web interface.
- Centralized library management.

## How to Run
1. Install Python.
2. Install Flask using `pip install flask`.
3. Open the project folder.
4. Run `python app.py`.
5. Open the local URL displayed in the terminal.

## Project Outcome
The system makes library management easier, faster, and more organized.
